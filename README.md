# 📝 Validación de Formularios con Zod

Mini proyecto desarrollado como parte del módulo de **Validación de Formularios con Zod de DEV.F**.

## 📌 Descripción

Aplicación web que simula un formulario de registro y utiliza la biblioteca **Zod** para validar los datos ingresados por el usuario, mostrando mensajes de error personalizados en tiempo real.

## ⚙️ Funcionalidades

- Capturar nombre, correo electrónico y contraseña.
- Validar los campos mediante esquemas de Zod.
- Comprobar la longitud del nombre y la contraseña.
- Verificar el formato del correo electrónico.
- Validar que la contraseña contenga una mayúscula y un número.
- Mostrar errores mientras el usuario completa el formulario.
- Confirmar cuando los datos cumplen las condiciones establecidas.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Zod

## 🎯 Objetivo

Practicar la validación de datos mediante esquemas de Zod y mejorar la interacción con formularios utilizando mensajes de error claros y validaciones en tiempo real.

**Nota:** El registro es simulado. Los datos no se envían ni almacenan en un servidor.
